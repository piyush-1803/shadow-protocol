# Privacy and field safety

Use private, trusted groups only. For minors, arrange appropriate trusted adult supervision and do not admit strangers. There is no public room listing or nearby-player discovery. An invite code is a secret: anyone with both site access and the code can join before the match starts. This build does not verify a person's age or real-world identity.

Location consent is separate from joining. Exact GPS is available only to the server and the sending player. Room members get temporary approximate signals. Hosts cannot inspect an exact-position feed. No route history, third-party analytics, or precise-coordinate logs are created. Map providers see the viewer's IP and requested tiles. Free vector tiles use OpenFreeMap; compatibility mode uses OpenStreetMap standard raster tiles. Attribution is visible; there is no offline tile prefetching or service-worker API cache. Before higher-traffic deployment select a commercial or self-hosted raster provider and review its policy.

Only the latest position is stored. Positions expire after 60 seconds and gameplay ignores them after 15 seconds. Stop/leave/end performs direct deletion; normal cleanup is request-driven. No unattended physical-deletion deadline is promised. Rooms expire after 4 hours, session cookies expire after 24 hours; expired database identities are deleted on subsequent cleanup once room foreign keys no longer refer to them. D1 provider backups may retain historical records according to provider policy; do not promise erasure from backups from application deletes alone.

The host must choose a permitted outdoor place and inspect it in person. Never approve an arena crossing a dangerous road, body of water, restricted area, private property, structure requiring climbing, or inaccessible terrain. Draw exclusions or move/reduce the entire circle. Polygon validation rejects overlapping hazards; it does not identify every hazard. Accessibility varies among players: agree a safe arena and stop rules in advance. The game gives no navigation directions or incentive to sprint. Pause instead of trying to beat a hazardous boundary. Digital tags require no contact.

Anyone actively participating can safety-pause the game. GPS emergency stop is separate and immediate on-device. A disconnected host cannot resume or approve new shrink steps; players can stop or leave. Host departure ends the game. There is no host transfer or emergency-services dispatch. Do not rely on the game for personal safety.

This is an engineering field build, not a certified safety product. Required before broader launch: independent security review, abuse and retention operations, real-device outdoor tests, verified tile-provider capacity, background expiry cleanup, and validation with the intended age group.
