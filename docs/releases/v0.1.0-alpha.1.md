## Shadow Protocol — first alpha field build

A private-room, real-world multiplayer survival game for mobile browsers. Hunters follow approximate radar signals; Shadows evade until time expires. Tags are digital and require confirmation.

### Included

- Complete React/TypeScript frontend and Cloudflare Worker/D1 backend source.
- MapLibre/OpenFreeMap maps with a genuine Leaflet/OSM raster fallback.
- Persistent private rooms, guest identities, QR invitations and reconnect recovery.
- GPS uncertainty/freshness checks; server-assigned roles, timers and outcomes.
- Temporary approximate radar, reviewed zone shrink steps, confirmed tags and disputes.
- Ghost/Hunter Scan abilities, safety pause, emergency sharing stop and result handling.
- SQL migrations, environment example, setup/deployment instructions and 31 automated tests.

### Download and verify

Download `shadow-protocol-v0.1.0-alpha.1-source.zip` and `SHA256SUMS.txt`. In the download directory, run:

```bash
sha256sum -c SHA256SUMS.txt
```

This is a **source package**, not a standalone executable or an offline game. Use Node 24, install dependencies with `npm ci`, and follow the README for D1 initialization and HTTPS deployment. No secrets or runtime player data are included.

### Verification

The release workflow requires automated tests, TypeScript checks and a production build to pass before publishing this release. Previous local browser checks covered real D1 room creation, refresh recovery and raster-map rendering. These checks do not establish outdoor multiplayer reliability.

### Known limitations

- Alpha: no outdoor multi-phone or independent security/accessibility audit.
- Workers + D1 + polling, rather than the originally proposed Supabase/PostGIS/Realtime stack.
- Host-reviewed terrain and routes; no automated safe-route certification.
- Request-driven expiry deletion in the existing private hosted deployment. The optional standalone cron handler is provided but not remotely verified there.
- Browser GPS remains uncertain/spoofable and is stopped when the page becomes hidden.
- Existing hosted build is owner-private; room codes do not grant site-level access.

Consult the README and `docs/` before a controlled field test with trusted participants.
